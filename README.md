# AeroLink

适用于 **Windows 10 1809 及以上 x64、Windows 11 x64**。下载单个 `AeroLink-Win10-x64.exe` 即可使用，无需安装 Python。

**需要使用请添加微信：DeveloperFox。**

## 开始使用

1. 从 [GitHub Releases](https://github.com/JoeGuys130/AeroLink/releases/latest) 下载 `AeroLink-Win10-x64.exe`，放到有写入权限的固定文件夹（例如 `D:\Apps\AeroLink`），保持原文件名。不要直接在微信接收目录或更新临时目录运行。
2. 打开软件，输入已开通的账号和密码。个人电脑可勾选「自动登录」，共用电脑建议不勾选。
3. 进入「我的连接」，点击圆形电源按钮连接，再次点击即可断开。默认使用「规则（推荐）」和自动选线，也可在线路列表手动选择、重新检测。
4. 在「我的账号」查看共享流量与账号状态。同一账号下的设备共用月额度；遇到密码错误、设备停用或额度不足，请按提示联系管理员。

软件通过 Windows 系统代理工作，只影响使用该代理的应用。节点延迟是一次 TCP 连接耗时，不代表下载速度；线路是否可用以检测状态为准。

线路下拉框提供「自动选择」和各条具体线路，直接选择线路即固定使用。顶部和表格突出显示实际正在使用的线路；节点延迟表每30分钟刷新，也可手动检测。

自动选线以稳定为先：每60秒检查，当前线路连续3次失败、备用线路连续2次可用时才切换；自动切换后5分钟内不再次切换，恢复后也不自动切回。延迟波动不会触发换线；急需换线可手动选择。切线不重启本地核心，但出口IP可能改变，故障线路上的已有连接可能需要重连。

规则模式下，ip111.cn的国内检测按国内规则直连，国外检测使用当前线路；已修正国外检测子域名被国内后缀规则覆盖的问题。

## 托盘与退出

点击窗口右上角关闭按钮，会隐藏到右下角系统托盘，连接继续运行。双击托盘图标可重新打开窗口；右键图标可连接、断开或退出软件。完全退出请选择托盘菜单中的「退出」，软件会停止连接并恢复它修改的系统代理设置。图标可能收在任务栏的「显示隐藏的图标」中；系统托盘不可用时，关闭窗口会退出软件。

软件会记住上次成功连接状态，下次启动并通过账号和线路验证后可恢复连接。主动断开或退出账号会取消这项记忆。管理服务短暂不可达时，在现有授权有效期内保持连接并重试；授权到期则暂停，账号和线路重新验证成功后自动恢复，可点击电源按钮取消。账号撤销、凭据失效或额度耗尽仍停止连接。

从 1.0.2 起，同一用户重复打开只唤起已有窗口，隐藏到托盘时也不会重复启动。首次换用该版本前，请先从托盘退出旧版的所有窗口。

## 软件更新

点击左下角版本卡片打开更新窗口；登录页也有「软件更新」入口。软件每天最多自动检查一次，只提示新版本。点击「更新并重启」后，软件下载并校验新版，自动安全退出、替换原来的 AeroLink-Win10-x64.exe，再重新打开；连接会短暂断开，下载期间可以取消。不要运行更新目录或临时文件中的程序。更新检查和下载优先使用 AeroLink 当前连接，连接失败时尝试直连；未连接时使用系统网络设置并在失败后尝试直连。无法访问 GitHub 时仍可继续使用当前版本。

更新窗口提供「GitHub 发布页」按钮，可在浏览器中查找正式版本与下载记录；点击此按钮不会安装更新。

从1.0.4起，Windows 10/11 x64成品统一命名为 `AeroLink-Win10-x64.exe`，与其他平台区分。1.0.3及更早版本只识别旧附件名，首次需从发布页手动下载本版，退出旧版后替换；此后保留新文件名即可正常更新。

## 隐私与许可

软件向管理服务报告终端资料、MAC、代理流量和采样域名，供管理员管理账号与线路；不采集网页、聊天内容或完整 URL 路径，客户端不保存登录密码。服务端仍会按请求来源进行登录保护和安全审计。登录页可查看「隐私说明」。

许可证及所需对应源码随 EXE 提供：在软件更新窗口按 `Ctrl+Shift+L` 查看或导出。
