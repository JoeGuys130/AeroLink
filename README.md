# AeroLink

适用于 **Windows 10 1809 及以上 x64、Windows 11 x64**。下载单个 `AeroLink.exe` 即可使用，无需安装 Python。

## 开始使用

1. 从 [GitHub Releases](https://github.com/JoeGuys130/AeroLink/releases/latest) 下载 `AeroLink.exe`，放到有写入权限的文件夹，保持原文件名。
2. 打开软件，输入已开通的账号和密码。个人电脑可勾选「自动登录」，共用电脑建议不勾选。
3. 进入「我的连接」，点击圆形电源按钮连接，再次点击即可断开。默认使用「规则（推荐）」和自动选线，也可在线路列表手动选择、重新检测。
4. 在「我的账号」查看共享流量与账号状态。同一账号下的设备共用月额度；遇到密码错误、设备停用或额度不足，请按提示联系管理员。

软件通过 Windows 系统代理工作，只影响使用该代理的应用。节点延迟是一次 TCP 连接耗时，不代表下载速度；线路是否可用以检测状态为准。

## 托盘与退出

点击窗口右上角关闭按钮，会隐藏到右下角系统托盘，连接继续运行。双击托盘图标可重新打开窗口；右键图标可连接、断开或退出软件。完全退出请选择托盘菜单中的「退出」，软件会停止连接并恢复它修改的系统代理设置。图标可能收在任务栏的「显示隐藏的图标」中；系统托盘不可用时，关闭窗口会退出软件。

软件会记住上次成功连接状态，下次启动并通过账号和线路验证后可恢复连接。主动断开或退出账号会取消这项记忆。

## 软件更新

点击左下角版本卡片打开更新窗口；登录页也有「软件更新」入口。软件每天最多自动检查一次，只提示新版本。由你点击下载，校验完成后再点击「重启并更新」；更新会短暂断开连接，不会强制安装。无法访问 GitHub 时仍可继续使用当前版本。

## 隐私与许可

软件向管理服务报告终端资料、MAC、代理流量和采样域名，供管理员管理账号与线路；不采集网页、聊天内容或完整 URL 路径，客户端不保存登录密码。服务端仍会按请求来源进行登录保护和安全审计。登录页可查看「隐私说明」。

许可证及所需对应源码随 EXE 提供：在软件更新窗口按 `Ctrl+Shift+L` 查看或导出。
