# AeroLink

AeroLink 用于连接管理员提供的网络线路，支持自动选线、手动切换和账号流量查看。

· 联系微信：`DeveloperFox`

## 开始使用

1. 将 EXE 放到有写入权限的固定文件夹，例如 `D:\Apps\AeroLink`，保留下载文件名。
2. 打开软件，使用已开通的账号登录。
3. 在「我的连接」点击圆形电源按钮。默认使用「规则（推荐）」和「自动选择（推荐）」。
4. 需要换线时，直接点击线路卡片或在选择框中选择具体线路；当前线路标记为「使用中」。选择具体线路后会固定使用，选择「自动选择」可恢复自动选线。
5. 在「我的账号」查看流量、额度及账号状态。同一账号下的设备共用月额度。

自动选线优先保持稳定，当前线路持续异常后才尝试备用线路，不会因延迟略有变化就频繁切换。短暂断网后，网络、账号和线路恢复正常时会尝试重新连接；主动断开可取消恢复。延迟不等于下载速度，必要时可手动点击「重新检测」。

软件使用 Windows 系统代理，作用于遵循该代理设置的应用。使用前请退出其他代理软件；遇到代理冲突提示时，先确认其他代理已停止，再重新连接。

## 更新与退出

点击左下角版本信息打开更新窗口。软件每天最多自动检查一次；确认新版本后，点击「更新并重启」下载安装，完成后自动重新打开。更新期间连接会短暂中断。

**旧版首次升级：Windows 10/11 的 1.0.4 及更早版本、Win7 的 1.0.2 及更早版本，需要先从上方发布页手动下载本平台新版。** 这些旧版本不能正确识别当前共享发布页，已安装的旧程序不会自动获得更新器修复。

手动更换时，先右键任务栏右下角的 AeroLink 托盘图标，选择「退出」，再运行新版。点击窗口右上角的 × 通常只是隐藏到托盘，连接仍会继续。不要运行更新临时目录里的文件。

如果更新窗口暂时无法连接 GitHub，可以稍后重试或使用窗口中的「GitHub 发布页」手动下载；当前版本仍可继续使用。账号不可用、额度不足或线路不可用，请按界面提示联系管理员。

## 许可

开源许可证及所需对应源码随 EXE 提供。在软件更新窗口按 `Ctrl+Shift+L` 可查看或导出。
